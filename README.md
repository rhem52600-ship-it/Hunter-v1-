# HUNTER V1
Prototype Android anime/RPG fitness app.

## Build
Open this folder in Android Studio, allow Gradle sync, then run `app` on an Android device or choose Build > Build APK(s).

Target SDK: 36. The project uses a local WebView asset so the app's core UI works without a runtime internet connection.

## Compilation depuis Android
Voir `GITHUB_ANDROID.md`. Le workflow `.github/workflows/build-apk.yml` compile automatiquement l'APK sur GitHub Actions.
